# SEO audit · shftapp.vercel.app · 8 November 2026

Run with claude-seo 2.5.0 (render_page, parse_html, sitemap_discovery, agentic_check, preload_check).
PageSpeed Insights was rate-limited without an API key, so Core Web Vitals are not scored here.

## Fixed in this change (no visual change)
- Legal pages had no Open Graph, Twitter card or structured data: added og/twitter tags and
  WebPage + BreadcrumbList JSON-LD to privacy, terms, health-data, support, cookies, licenses.
- New `/licenses/` page with the CC BY-SA 4.0 attribution the exercise illustrations require
  (they appear in the app screenshots on the homepage); added to the sitemap and every legal footer.
- Privacy, terms and health-data brought in line with app 1.20 (payments, usage events, EU storage,
  subscription terms, morning self-check).
